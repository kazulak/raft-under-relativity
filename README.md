# Raft under physical communication models

Minimal research repository.

- `paper/main.typ` is the article. Build it with `typst compile paper/main.typ`.
- `paper/refs.bib` is auto-exported from the Zotero collection "Raft" by Better BibTeX. Don't edit it by hand.
- `review/studies.csv` holds one row per screened record (screening, eligibility, exclusion codes).
- `review/cards.md` holds the data-extraction cards for the included studies.
- `review/blind-check.csv` and `review/litmaps-forward.bib` are the screening check and the forward-citation export.
- `review/pdf/` holds the full texts locally; it is git-ignored.
- The simulator and experiment code that preceded this layout live in git history (before commit `396b3c8`).

Phase 2 (formal/analytical work) begins only after the review answers RQ4.
